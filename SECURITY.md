# Security Policy

This repository is private and contains NEO AI intellectual property.

## Prohibited material

Never commit:

- API keys
- passwords
- access tokens
- private keys
- certificates containing private material
- production secrets
- personal KYC data
- investor identity records
- unrestricted production database dumps
- model weight files
- cloud credentials

Secrets must be managed outside Git through approved secret-management systems.

Security-relevant changes must be documented and reviewed before production deployment.
