# Superseded build artefacts

`neoai.myneogroup.com_research-delta-v1.0.0/` is the static HTML delta built for the
research section of neoai.myneogroup.com in August 2026, from capability register v1.3
and the v1.0 texts of the Wave 1 publications.

It was moved here on 2026-10-18 and must not be deployed. It renders capability
statuses that are no longer correct (for example LILI and the orchestration layer at
"designed and specified", while register v2.0 records them in operation at S2) and
capability pages under keys that register v2.0 retires.

The replacement delta is built from `content/` and `registers/` at corpus version
0.2.0 by the site build. Until that build exists, nothing in this folder is a current
description of the platform. It is kept, unmodified, because a superseded artefact
stays inspectable rather than disappearing.
