Research

The public research corpus. Every material statement carries a claim class, and every capability reference resolves to a published register.

How to read this corpus

[E]Established. An external primary source is cited.
[A]Architectural interpretation. An inference the Program holds and has not proved.
[D]Design intent. Carries a capability status from the register.
[O]Open problem. Named and unsolved.

Capability statuses resolve from the Capability Register, version 1.2, marked provisional. Nothing here describes a deployed system unless its status says so.
