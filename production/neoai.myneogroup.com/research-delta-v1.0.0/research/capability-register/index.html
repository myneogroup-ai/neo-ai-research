Capability Register

Every capability NEO AI describes, with its status. A page that describes a capability links to its row here, and the status rendered on that page is resolved from this register when the page is built.

Register version 1.2. PROVISIONAL - requires Founder confirmation before any capability status is treated as ratified. Last updated 2026-08-10.
