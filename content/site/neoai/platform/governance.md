# Human authority

## Header

**Who decided, and were they entitled to**

## Body

Most AI governance is a document. A document does not stop anything at runtime.

NEO AI is designed so that governance is a state transition rather than a policy statement. Two questions are kept separate because collapsing them produces an audit trail that records permission without entitlement: **may this happen**, and **who was entitled to decide it happens**.

An approval is an object with a scope and a lifetime, not a click. It can expire. It can be invalidated by a change in what it was granted against. A mission runs inside an envelope set when it is created; the envelope can contract automatically and expands only by explicit authority. Recovery from a fault never expands it.

## Autonomy is derived, not configured

How much a system may do without asking is derived from how reversible the action is and how consequential it would be if wrong. The derivation is published.
