# Intelligence Profiles and NEO Credits

## Header

**The person chooses an Intelligence Profile, not a model**

## Intelligence Profiles

NEO is not a model switcher and not an API reseller. The person selects how much intelligence a Mission should mobilise; NEO decides which models, agents, tools, memory and compute deliver it. As the Execution Fabric and Edge Compute arrive, it also decides how much of that envelope comes from the device, NEO, private infrastructure or external models. Profile is not provider, and provider is not execution location. `[D] (intelligence-profiles, S3)`

Five public profiles form the family: **NEO AUTO**, NEO decides the envelope; **NEO PULSE**, fast and efficient; **NEO PRIME**, balanced; **NEO AXIOM**, deep reasoning; **NEO APEX**, maximum justified intelligence, not indiscriminate compute. The one-line descriptions indicate intent and are not published specifications.

Mode is visibility; profile is the resource envelope. Every combination of the three projections and the five profiles is valid: FOCUS with APEX and JARVIS with PULSE are both legitimate.

## Six dimensions that never collapse, plus one

Mode (visibility), Intelligence Profile (resource envelope), Context (read access), Authority (side effects), Memory (persistence) and Training eligibility (improvement) are six independent dimensions, never collapsed into one switch. Local Compute Permission is a seventh: GPU use never authorises reading files, acting or training.

Personal context gives NEO read access to what the person chooses to share; it is never model training, and broad computer access never implies training permission. Help Improve NEO is a separate, explicit choice, off by default, with no pre-ticked global consent.

## NEO Credits, the usage unit

Customers buy and consume NEO Credits. Provider tokens, GPU seconds and edge execution remain internal metering only. The chain from execution usage, to internal resource accounting, to a normalised NEO resource, to NEO Credits stays separated, so pricing follows the intelligence delivered and not any provider's token bill or the location where work ran. `[D] (neo-credits, S4)` `[D] (core.resource-accounting, S3)`

Subscriptions include a level of NEO Credits, and Intelligence Profiles consume them at different envelopes. NEO Credits are a commercial usage unit and not a cryptocurrency, a transferable token or a financial instrument, not a provider price and not a promise of a volume of output. Credit allowances and per-Credit prices are commercial parameters set at the launch of each plan and are not stated here.

## Status

Intelligence Profiles: implemented and in validation. `[D] (intelligence-profiles, S3)` NEO Credits: defined as the customer-facing unit, with pricing not set. `[D] (neo-credits, S4)`
